Problem statement

The goal is to implement multiple classification models on a chosen dataset, evaluate their performance using various metrics,
and deploy an interactive Streamlit web application to demonstrate the models' predictions without retraining on the fly.

Dataset description

Item Value
Dataset Breast Cancer Wisconsin (Diagnostic) Dataset from UCI.
Features 30 numerical features computed from a digitized image of a fine needle aspirate (FNA) of a breast mass.
Instances 569 instances.
Target Binary classification (Malignant or Benign).

Models used

Logistic Regression
Decision Tree 
KNN 
Naive Bayes 
Support Vector Machine
